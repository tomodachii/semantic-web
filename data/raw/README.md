# Raw Kaggle inputs

Download and extract both files from:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata/data

Place these files in this directory:

- `tmdb_5000_movies.csv`
- `tmdb_5000_credits.csv`

Keep the original files unchanged. Run `python scripts/prepare.py` from the project directory to generate the cleaned tables in `data/prepared/`.
